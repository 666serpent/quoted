# Changelog

## 1.1.0 — 2026-11-26

First public release of Quoted.

- Native Liquid Glass lyrics window for the Spotify desktop app.
- Manual scrolling, SF Semibold text, and quieter section labels.
- Drag the reading surface to move the window; no text selection or visible scrollbar.
- Centered song credits with links to artist and producer profiles on Genius.
- Genius-first lyric matching, LRCLIB fallback, and remembered manual corrections.
- Native macOS icon with dark, clear, and tinted appearances.
- No tray icon; closing the window quits the app.
